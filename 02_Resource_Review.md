# Resource Review

## Data Resources

### 1. FinTrust_Customer_Data.csv

Purpose:
- Understand the FinTrust customer population
- Identify customer-related variables
- Support customer behaviour analysis

Expected use:
- Data profiling
- Customer analysis
- Customer segmentation where supported by the available fields

Limitation:
- Analysis is limited to the fields and quality of the supplied dataset.

### 2. FinTrust_Transaction_Data.csv

Purpose:
- Understand transaction activity
- Analyse transaction value
- Analyse transaction channels
- Analyse transaction status
- Explore risk-related patterns

Expected use:
- Transaction profiling
- KPI calculations
- Transaction trend analysis
- Dashboard development

Limitation:
- Analysis is limited to the fields and quality of the supplied dataset.

### 3. FinTrust_Data_Dictionary.xlsx

Purpose:
- Understand the meaning and definitions of dataset fields
- Confirm expected data types
- Support accurate interpretation of the datasets

Limitation:
- Field definitions should be checked against the actual supplied data.
