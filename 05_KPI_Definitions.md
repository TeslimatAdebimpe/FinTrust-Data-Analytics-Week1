# KPI Definitions

| KPI | Definition | Why It Matters | Required Data |
|---|---|---|---|
| Total Customers | Count of unique customers | Measures customer base | Customer ID |
| Total Transactions | Count of transactions | Measures transaction activity | Transaction ID |
| Total Transaction Value | Sum of transaction amounts | Measures monetary transaction activity | Transaction Amount |
| Average Transaction Value | Total transaction value divided by transaction count | Shows typical transaction size | Transaction Amount |
| Successful Transaction Rate | Successful transactions divided by total transactions | Measures transaction performance | Transaction Status |
| Transaction Failure Rate | Failed transactions divided by total transactions | Highlights unsuccessful transaction activity | Transaction Status |
| Risk Review Rate | Risk-reviewed transactions divided by total transactions | Supports monitoring of risk-related patterns | Risk Review Field |
| Transactions by Channel | Transaction count grouped by channel | Shows channel usage | Transaction Channel |
