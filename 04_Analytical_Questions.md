# Analytical Questions

The following questions will guide the FinTrust Data Analytics work:

1. What is the size and profile of FinTrust's customer base?

2. How does transaction activity change over time?

3. What is the total and average value of transactions?

4. Which transaction channels are used most frequently?

5. What proportion of transactions fall into each transaction status?

6. How does transaction behaviour vary across available customer categories?

7. Are there observable patterns in transaction activity or value associated with the risk-review field?

8. Which customer and transaction patterns should management monitor through a business intelligence dashboard?
